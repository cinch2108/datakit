Questions

Is it really free?

Yes. There is no server doing the work, so there is nothing to meter: no row limits, no daily quotas, no sign-up. Reserved ad space keeps it free.

Is my data uploaded?

Never. Files are read and processed by JavaScript in this tab. The 0 bytes uploaded counter, and your browser's network panel, will confirm it. You can even keep working offline once the page has loaded.

Which formats are supported?

CSV, TSV, Excel (XLSX, XLSM, XLSB, XLS), OpenDocument (ODS), JSON and JSON Lines, XML, YAML, Markdown and HTML tables as input. You can write any of those, plus SQL INSERT statements.

How big can my files be?

Hundreds of thousands of rows are fine on any modern laptop, and the viewer scrolls 100,000+ rows smoothly. The limit is your device's memory, usually a few hundred MB per file.

Does it work on my phone?

Yes. Every tool works on modern mobile browsers. Phones have less memory, so very large files work best on a computer.
