      About the join files (vlookup)

      You have orders in one file and customer details in another, and you need them side by side. In Excel that means VLOOKUP or XLOOKUP formulas copied down thousands of rows, which is slow, fragile and easy to get wrong. This tool joins the two files on a key column in one step, the way a database does. Choose a left join to keep every row of file A, inner for matches only, full outer to keep everything, or right join. Keys can be matched ignoring case and spaces, and the preview shows how many rows matched.

      How to use it

      1. Drop file A (the main table) first, then file B (the lookup table). The badges show which is which.
      2. Pick the key column in each file, such as Customer ID. Matching names are picked automatically.
      3. Choose the join type and matching options.
      4. Check the match counts in the preview, then press Join files and download.

      Tips for the best results

      • Use only the first match, like VLOOKUP, when file B can contain the same key several times.
      • Columns with the same name in both files are suffixed so nothing is overwritten.
      • Swap A and B with the arrows in the file list.

      Settings explained

      How it works: the second file is indexed by its key column in a hash map, so joining takes one pass over each file, even with hundreds of thousands of rows. Keys can be compared ignoring case and surrounding spaces. Columns from file B whose names already exist in file A get a suffix, so nothing is overwritten.

      Why use Sheetwise for this: most online join files (vlookup) sites upload your spreadsheet to their servers, where it may be logged, kept or seen by staff, and many cap the rows or file size unless you pay. Here the file is read straight from your disk by JavaScript in this tab, processed in memory and handed back as a download. A strict Content Security Policy stops the page from contacting other servers, so the counter above always reads 0 bytes uploaded.

      Frequently asked questions

      Is this the same as VLOOKUP?

      A left join with Use only the first match behaves like VLOOKUP, but it brings in every column of file B at once and does not break when columns move.

      What happens to rows without a match?

      In a left join they are kept with empty B columns, and the preview counts them.

      Are my files uploaded anywhere?

      No. The file is read by your browser and processed in this tab with JavaScript. Nothing is sent to a server, which you can confirm with the 0 bytes uploaded counter or your browser's network panel.

      How large a file can it handle?

      Files up to a few hundred megabytes and several million cells work on a typical laptop. The real limit is your device's memory, since everything stays in the tab instead of going to a server.
