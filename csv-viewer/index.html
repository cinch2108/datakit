      About the csv viewer & editor

      Excel stops at 1,048,576 rows, takes ages on big files, and mangles some values on open. Text editors show CSV as an unreadable wall of commas. This viewer parses the file in a background worker and shows it in a virtualized grid that only draws the rows and columns on screen, so a file with hundreds of thousands of rows scrolls smoothly. Click a header to sort and see column statistics, type in the filter row to narrow things down, and double-click any cell to fix it. Export the result as CSV, Excel, JSON and more.

      How to use it

      1. Drop a CSV, TSV, Excel, JSON or XML file onto the box above, or press Try sample to load 100,000 rows.
      2. Scroll, search all cells, or type in the filter boxes. Filters accept text, >100, <=5, =exact, empty and !empty.
      3. Double-click a cell to edit it, and use the toolbar to add or delete rows and columns.
      4. Choose an export format and press Export to save your changes.

      Tips for the best results

      • Click a column header to sort it ascending, again for descending, and a third time to clear the sort.
      • Tick Export only the filtered and sorted rows to save just the subset you are looking at.
      • Keyboard: arrow keys move between cells, Enter edits and saves, and Escape cancels.

      Settings explained

      How it works: the file is parsed in a background worker, and the grid is virtualized, so only the rows and columns on screen exist in the page at any moment, which is why 100,000+ rows scroll smoothly. Sorting is numeric-aware (2 sorts before 10) and uses natural ordering for text. Filters are applied per column and combined, while search looks in every cell. Edits change the in-memory copy only, until you export.

      Why use Sheetwise for this: most online csv viewer & editor sites upload your spreadsheet to their servers, where it may be logged, kept or seen by staff, and many cap the rows or file size unless you pay. Here the file is read straight from your disk by JavaScript in this tab, processed in memory and handed back as a download. A strict Content Security Policy stops the page from contacting other servers, so the counter above always reads 0 bytes uploaded.

      Frequently asked questions

      How many rows can it open?

      Hundreds of thousands of rows open smoothly on a typical laptop, and a few million rows work with enough memory. Only the visible rows are drawn.

      Can I edit and save the file?

      Yes. Edit cells, rename columns, add or delete rows and columns, then export as CSV, Excel, JSON, TSV, Markdown or HTML.

      Are my files uploaded anywhere?

      No. The file is read by your browser and processed in this tab with JavaScript. Nothing is sent to a server, which you can confirm with the 0 bytes uploaded counter or your browser's network panel.

      Does it open Excel files too?

      Yes. XLSX, XLS and ODS files open with a sheet picker.
